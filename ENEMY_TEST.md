# Enemy test 1

This revision adds four Goombas at the original opening-section placements to the
existing textured terrain test. Walking, camera activation, wall reversal, falling,
stomping, bounce, side-contact death and restoring enemies after restart are
implemented with bounded portable C state. This remains approximate gameplay.
Mario is still the yellow player. Goombas use temporary brown shapes with eyes
and feet; these are authored test visuals, not converted Wii models. Audio,
power-ups, working coins, animated blocks and the other enemy types remain absent.

## Build and data

Push this source to the existing GitHub Actions workflow. The native build now
compiles `enemies.c`; host tests also run `enemies_tests.c`. Native compilation and
handheld testing of this revision are pending. No prior terrain timing result
establishes enemy-test performance.

The original `terrain.nst` and `terrain.rgba` are unchanged. Add the separate local
enemy data generated by:

```text
python tools/package_enemies.py PATH_TO_EXTRACTION PATH_TO_TERRAIN_NST NEW_OUTPUT_DIRECTORY
```

Copy `enemies.nse` to `3ds/nsmbw-prototype/data` with the next executable. It is
bound by checksum to the matching terrain package. Original-derived placements
stay outside the public repo. The converted file contains four actor-20 positions:
local (992,144), (608,208), (784,176), (1232,176). The converter preserves course
order and rejects unsupported settings for these actors.

Launch through the previously working Homebrew Launcher route. After the two A
prompts, expect **ENEMY TEST 1** and a Goomba count of 4. Missing or mismatched
enemy data produces a startup message and a clearly labeled terrain-only mode.

Use the existing controls. Jump onto Goombas from above to squash them; holding
jump gives a higher bounce. Touching a Goomba from the side causes a death and
restores the section after 45 unpaused updates. Touchscreen restart restores
player and enemies immediately. Start pauses both. Select cycles modes and resets
the encounter when re-entering it. Select+Start saves the CSV and exits.

## Tests completed locally

- Portable C: invalid/truncated/wrong-terrain/unsupported-actor packages, 100
  repeated loads, activation, walking, wall turns, stomp, squash lifetime,
  contact death, pause, respawn and falling enemies pass under WebAssembly.
- Real converted package: four Goombas load; leaving the player stationary leads
  to contact damage. An automated run/jump traversal completes in 346 fixed steps
  without deaths (it avoids the Goombas rather than stomping them). Stomping is
  covered separately by the synthetic encounter test.
- Existing movement and terrain regression tests pass after sharing their
  collision integration with enemies.
- Python: 38 tests run, 37 pass, one optional local-data test skips.

Goomba-on-Goomba turning is approximate. Enemy/player collisions use swept
vertical crossing and current horizontal overlap; this is not a full Wii actor
collision reconstruction. Ramp side/underside limitations from TERRAIN_TEST.md
still apply. Missing enemy data does not disable the terrain-only fallback.

## Character resource audit and remaining work

The local archives contain `Mario.arc/g3d/model.brres` (378752 bytes) and
`kuribo.arc/g3d/kuribo.brres` (47232 bytes). A bounded header scan identifies
MDL0 version 11 model and TEX0 version 3 texture sections in both, plus CHR0
version 5 animations in the Goomba resource. Mario also has a separate
`P_rcha.arc` available for further animation inspection. These findings are an
inventory, not a validated BRRES decoder.

The native renderer currently supports a flat tile atlas. Original characters
still need a model/vertex/material/animation converter and a runtime rendering
path, or validated offline animation baking. No character textures alone can
replace the complete animated models. The BRSAR sound archive likewise still
needs sound extraction/decoding and a native audio system. These tasks remain
open; this revision does not claim to implement them.

[Reggie-Next's actor definition](https://github.com/NSMBW-Community/Reggie-Next/blob/master/reggiedata/spritedata.xml)
identifies actor 20 as Goomba using `kuribo.arc`; checked 2026-09-09. The native
behavior here is independently authored, not copied Wii executable code.
